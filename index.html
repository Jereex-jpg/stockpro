Resumen

Cómo se usa

  1. Ingresar: con usuario y contraseña. El administrador ve todo; el empleado solo mueve stock.
  2. Panel: muestra totales, alertas de faltante y un gráfico por categoría.
  3. Inventario: el administrador agrega, edita o elimina productos. Cada producto tiene un mínimo: si el stock llega a ese número, aparece “Bajo”.
  4. Movimientos: con los botones Entrada, Venta y Ajuste se cambia el stock y queda registrado quién, cuándo y por qué.
  5. Proveedores: se cargan y se asignan a cada producto.
  6. Reportes: imprimir o guardar en PDF, y descargar CSV para Excel.

Cómo funciona por dentro

  • HTML arma la estructura, CSS el diseño (también responsive y modo oscuro).
  • JavaScript guarda un arreglo de objetos por producto y recalcula todo al cambiar algo.
  • Los datos se guardan en localStorage del navegador. Para un sistema real se usaría una base de datos en un servidor.
  • Cada movimiento es un registro con fecha, usuario, producto, tipo y cantidad.
